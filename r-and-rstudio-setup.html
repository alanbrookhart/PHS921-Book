A R and RStudio setup

This appendix collects the one-time setup we assumed you had already done, back in Chapter 2. If everything already works, meaning that you can knit a chapter and see ns and sta load without complaint, you can skip past it.

A.1 Installing R and RStudio

Install R first, then RStudio. Both are free.

  • R: download and install the current release from CRAN, the Comprehensive R Archive Network. Pick the installer for your operating system and accept the defaults.
  • RStudio: download and install RStudio Desktop from posit.co/download/rstudio-desktop. RStudio is an editor for R, not a replacement for it, so R must already be installed before RStudio is any use.

Open RStudio once, just to confirm it starts and finds your R installation (it will say so in the Console pane on startup).

A.2 Installing the packages this book uses

Every chapter in this book leans on the tidyverse for data manipulation and plotting, and most chapters bring in one or two special-purpose packages on top of that. Install all of them at once by pasting the following into the R console and running it:

install.packages(c(
  "tidyverse",  # dplyr, ggplot2, purrr, and friends
  "bookdown",   # builds this book; only needed if you render it yourself
  "dagitty",    # causal diagrams, Chapter 5
  "ggdag",      # plotting causal diagrams, Chapter 5 and later chapters
  "survival",   # Surv(), survfit(), survSplit(), Chapters 10-12
  "cobalt",     # covariate-balance tables and plots, Chapter 8
  "geepack",    # weighted GEE, the engine behind iptw_estimator() and
                # ipcw_estimator(), Chapters 9 and 11
  "broom",      # tidy() for turning model objects into tibbles
  "remotes"     # installs packages from GitHub, including NAMCS below
))

One package used in Chapters 11 and 12, splines, ships with base R and never needs installing.

A.3 Installing the NAMCS teaching package

The two cohorts this book uses throughout, ns and sta, are not on CRAN. They live in a companion package, NAMCS, distributed from GitHub. With remotes installed from the previous step, run:

remotes::install_github("alanbrookhart/NAMCS")

If that command fails, it is almost always one of two things: remotes is not installed (revisit the previous step), or GitHub is unreachable from your network (try again from a different network, or ask your instructor for the data files directly).

A.4 Loading everything a chapter needs

Every chapter and appendix in this book opens with a chunk that runs

source("R/setup.R")

R/setup.R loads the tidyverse and the NAMCS package, loads ns and sta, and derives the handful of analysis columns and covariate lists (ns_covs, sta_covs, and so on) that later chapters take for granted. Sourcing it is the whole of what you need to do to follow along with any chapter’s code on its own, without having run the earlier chapters first.
