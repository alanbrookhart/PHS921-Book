C The estimator toolkit

Across the book we wrote one small function per chapter, each solving the identification or estimation problem that chapter introduced, and each built to be reused rather than thrown away. This table collects all of them in one place, giving the name of each, the chapter that introduced it, what you hand it, and what it returns. Every one of them lives in its own file under R/, and is loaded with source("R/<file>") after the source("R/setup.R") that opens every chapter — exactly as the chapters do it. One dependency is worth naming: iptw_estimator() calls est_ps(), so source R/propensity.R alongside R/iptw_estimator.R.

Table C.1: Estimator and helper functions defined in R/, in the order they are introduced.
Function File Ch. Signature Returns
table1_continuous table1.R 2 table1_continuous(data, vars, by) Tibble of mean (SD) for each continuous variable, one column per level of by.
table1_categorical table1.R 2 table1_categorical(data, vars, by) Tibble of n (%) for each level of each categorical variable, one column per level of by.
standardize standardize.R 7 standardize(data, outcome_model, treat, family = binomial(), n_boot = 200, conf_level = 0.95, seed = NULL) Tibble with one row per estimand (risk0, risk1, rd, rr) giving the point estimate and a bootstrap confidence interval, from parametric g-formula standardization.
est_ps propensity.R 8 est_ps(data, treat_model) The input data with a ps column added, holding fitted propensity scores from a logistic regression.
ps_match propensity.R 8 ps_match(data, treat, ps = “ps”, caliper = 0.05) Matched-pairs data frame from greedy 1:1 nearest-neighbor matching on ps, without replacement, with a pair_id column.
iptw_estimator iptw_estimator.R 9 iptw_estimator(data, treat_model, outcome, treat, family = gaussian(), stabilize = TRUE, truncate_at = NULL) Tidy tibble (via broom::tidy()) of a weighted-GEE treatment-effect estimate with a robust confidence interval, from stabilized or unstabilized IPTW.
plot_km km.R 10 plot_km(data, treat, time = “event_time”, event = “cv_event”, wt = NULL, labels = NULL) A ggplot object: cumulative incidence curves by treatment arm, with confidence bands, optionally weighted.
make_person_period ipcw.R 11 make_person_period(data, time, event, cuts) Person-period expansion of one-row-per-patient survival data, via survival::survSplit().
ipcw_estimator ipcw.R 11 ipcw_estimator(pp_data, censor_model, outcome_formula, id = “.row_id”, numerator_model = NULL, truncate_at = 0.99) A list with fit (tidy weighted-GEE coefficients) and data (the person-period data with censoring weights attached), from IPCW.
ccw_estimator ccw_estimator.R 12 ccw_estimator(pp_data, censor_model, treat, id = “.row_id”, numerator_model = NULL, truncate_at = 0.99) Tibble of hazard, survival, and cumulative risk by treatment arm and interval, from the clone-censor-weight algorithm.
iv_estimator iv_estimator.R 13 iv_estimator(data, instrument, treat, outcome, covs = NULL, n_boot = 200, conf_level = 0.95, seed = NULL) Tibble with one row giving the two-stage-least-squares estimate and a bootstrap confidence interval.
evalue_rr sensitivity.R 14 evalue_rr(rr, conf_low = NULL, conf_high = NULL) Tibble giving the E-value for the point estimate and, if a confidence interval is supplied, for the bound closest to the null.
adjust_rr_unmeasured sensitivity.R 14 adjust_rr_unmeasured(rr_obs, p_u1, p_u0, rr_ud) A single numeric: the risk ratio that would remain after removing the bias contributed by a specified unmeasured binary confounder.
